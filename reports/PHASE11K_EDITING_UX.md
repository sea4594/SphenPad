# Phase 11K — creator editing UX parity

Phase 11K improves the authoring workflow on top of the Phase 11A–11J model/persistence/playtest stack. It does not add a second renderer or change the Phase 1–10 solver/player architecture.

## Completed

- Creator definition history is exposed through standard keyboard undo/redo (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z`, `Cmd/Ctrl+Y`) as well as the existing buttons. Grouped bulk/clipboard/path operations create one definition history step and continue through the existing autosave path.
- Multi-object selection is available in the object list using checkboxes, modifier-click, or creator multi-select mode. `Cmd/Ctrl+A` selects all objects for the active element.
- Bulk editing supports enable/disable, duplicate, delete, copy, opacity/color, send-to-back/bring-to-front, cosmetic alignment, and snapping.
- Authored constraints/cosmetics can be copied and pasted through a versioned `sphenpad-creator-objects` clipboard payload. The system clipboard is used when available with an in-app fallback. Pasted objects receive fresh stable IDs and automatically activate their creator catalog element, so cross-project paste remains editable.
- Right-clicking an object opens creator context actions. The ordinary `...` object menu remains available for touch/non-context-menu workflows.
- Line/path objects expose individual points. Points can be selected, replaced from the current board cell, nudged, inserted, deleted, and drag-reordered without replacing the complete path. Native visuals are regenerated by the existing semantic line builder, preserving the object's style.
- Cosmetic objects can be aligned left/center/right/top/middle/bottom and snapped to cell centers or grid intersections.
- Layer ordering now includes one-step backward/forward and absolute send-to-back/bring-to-front operations.
- Creator board navigation has 50%–250% zoom, reset, pan controls, Ctrl/Cmd-wheel zoom, and `+`/`-` keyboard zoom.
- Per-tool appearance/clue defaults can be saved from an authored object. Defaults persist in CreatorProject metadata and are applied to subsequently-created objects of that element type.
- Keyboard creator actions include copy, paste, select-all, delete, Escape/cancel, undo/redo, and zoom shortcuts while respecting text/input focus.

## Architecture

The reusable operations live in `src/sudokupad/creator/editingUx.ts`. They operate on the same `PuzzleDefinition` / `SudokuPadScene` / `PuzzleLogic` authoring state used by previous Phase 11 slices, making clipboard, bulk, alignment, path-point and layer operations testable without React.
